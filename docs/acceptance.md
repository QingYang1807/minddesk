## 已执行并通过

- `npm run check`：严格 TypeScript 类型检查。
- `npm run test:core`：16 项 Vitest，工作目录为 packages/core。
- `npm run build`：Vite 生产构建，无外部 CDN。
- 真正的临时 SQLite 数据库写入、关闭、重新打开、任务/备注/主题字段一致、快照恢复、整库备份恢复，坏备份不破坏原数据。
- 根/环/父引用/重复 ID/关联端点校验，真实节点移动与删除。
- Markdown 标题混合五级列表的层级关系；空内容和不兼容 XML 拒绝。
- 六种布局的有限坐标与节点互不相交；中文与 XML 特殊字符 SVG 转义。
- 50 / 200 / 500 节点的纯布局与完整 SVG 序列化。
- AI 建议的隔离副本、引用校验、根删除拒绝、失败不改变原文档。

`artifacts/performance.json` 记录了单次运行的原始基准，**只包含纯布局和 SVG 序列化**。未测浏览器帧率、拖动延迟、PNG 内存峰值，因此不能等同于「500 节点流畅操作」。

## 尚未完成或仍有限制

- 最终浏览器验收、80/150 节点视觉优化、中文输入法现场验证、触控板和所有拖拽手势实测。
- AI 不可达/错误密钥/超时/取消/损坏 JSON 的完整真实传输层异常矩阵。
- 布局局部稳定性：目前重算可见树并动画过渡，尚无增量子树缓存；分支平衡可能随内容调整而更换左右分配。
- 手动拖动可能造成碰撞；一键美化会清除位置约束并重新排版。自动布局有碰撞检查，未做任意手动约束的碰撞修复。
- 鱼骨对普通文档直接使用一级分类，未加入分类映射向导；6M 独立模板未完成。
- 「极简曲线」和「自然曲线」目前曲率相同，主要线宽差异；尚未形成完全不同的连接路由算法。
- WBS 有任务清单和树形布局，没有完整看板、依赖调度、权重评分矩阵。
- 关系可持久化和编辑，尚未绘制交叉引用连接线。
- 侧栏大纲搜索能筛选与选择节点，精确画布定位使用底部定位按钮。
- 命令面板目前为动作列表，没有输入过滤；库的标签分类管理较基础。
- 格式导入预留 FreeMind / XMind / OPML，首版明确拒绝，不做静默转换。
- PDF 尚未实现；Markdown 只能导出文字层级，完整属性用 JSON 保留。
- 快照历史没有可视化差异对比，历史内存限 80 次，未跨应用重启持久化撤销栈。
- 当前适配 OpenAI 兼容 Chat Completions；不支持只提供 Responses API 的服务。
