# Mind Desk 产品与技术设计

用户已授权自主设计和实施。目标是每日可用、数据本地保存的专业思考工作台。优先保证创建—编辑—保存—恢复—导出完整链路，再扩展多视图与真实模型。

## 方案比较与决策
- React Flow：成熟平移、选择、缩放、拖拽；自动布局和专业节点需自行实现。适合多个共享领域模型的视图。
- Mind Elixir：内建思维导图交互，上手快；统一鱼骨/WBS/其他视图需要较多适配。
- 自建 SVG 交互：导出一致但需要重建交互基础设施。
选择 React Flow 交互 + 独立纯函数布局 + SVG 导出。官方依据：https://reactflow.dev/learn/layouting/layouting ，https://github.com/ssshooter/mind-elixir-core 。

## 分层
packages/core/src：Zod 文档领域、结构编辑命令、导入、布局、主题、SVG、模板。server：Fastify、SQLite 迁移/快照/备份、模型适配。src：React 页面与 Zustand 历史/保存、画布、大纲、任务和属性编辑器。
单一 Document 对象，视图仅保存显示配置。稳定 UUID，所有入口完整验证根、无环、父引用、关系端点。布局不修改业务节点。节点宽高按中英文字宽估算并换行，用子树包围盒分配空间。双侧按分支高度平衡；树形使用层宽和子树尺寸；鱼骨采用真正主干/斜骨/交错原因区。手动偏移按视图保存。

## 设计系统
暖白背景、细边界、深灰文字、紫色动作。14px 界面正文、12px 辅助信息。四套独立文档主题 Executive / Consulting / Creative / Dark，主题只影响视觉。中心实色、一级浅色容器、下级轻边界。左导航 220px，属性 260px，可隐藏，画布优先。实际内容缩略图。

## 可靠性与边界
SQLite WAL、同步 FULL、事务保存及快照，防抖写入、导航前刷新保存、失败保留编辑状态。API Key 仅保存在后端权限 0600 的本地设置文件，不返回浏览器。AI 先校验、逐项预览应用、正常撤销，失败不修改文档。只监听 127.0.0.1；无遥测、无 CDN、无自动云请求。云调用需用户在设置中明确启用。

## 验收
核心结构/导入/布局/导出测试；真实 SQLite API；Playwright 编辑恢复/五视图/导出/异常。30、80、150 节点截图、50/200/500 布局和导出。人工查看截图后至少一次修改。不能把未测 AI 或手动交互写作通过。
